# 驾驶主界面与显示规则

驾驶员视角是唯一主界面。画面以道路、货车及远处道路消失点组织视线，操作按场景回放、位置质量、显示策略分组。控制台放在风挡下方，可收起。全屏保留同一个播放时间。技术说明与链路参数使用可关闭的对话框。

|层|坐标与内容|显示约束|
|---|---|---|
|A 真实世界|世界米制场景，包括可见车辆、道路、树木、货车、驾驶舱下缘|共享相机和场景时钟，深度缓冲遮住后车|
|B 世界锁定|投影估计车辆轮廓或区域，短引线连接 ID 和距离|一个主目标。轮廓绑定估计，标签作旁注。镜头缩放与画布改变时同步计算|
|C 屏幕锁定|低质量或超出视场时显示方向，不可用时显示链路状态，左下角显示自车速度|保留路面视野；撤除失效目标的精确框|
|D 控制台|深石墨背景、低对比边框，轨迹播放、质量预设、两个策略、参数|当前选项有选中底色和按压语义。角标明确课程仿真和程序化素材|
|E 开发诊断|开发服务器加 ?debug 输出当前估计、时刻、σ、风险和决策原因|生产构建不显示调试数据|

|状态|形状与位置|颜色及含义|
|---|---|---|
|正常／确认|有依据且误差小，世界锁定实线车辆轮廓|浅薄荷色标记跟踪，文字标确认|
|估计|虚线区域包围投影中心，宽度与横向 σ 对应|文字标估计；达到注意阈值时用琥珀色|
|降级|撤去世界图形，在屏幕固定区域提示方位|暖色提示定位限制，状态条给原因|
|不可用|仅保留明确的过期/未知说明|撤除目标方向和距离|

三项核心演示依次是前车遮挡（本轮实现），侧向及后向协同风险（R4，引入多方向轨迹和方位边界），雨雾/逆光条件下的可信度降级与恢复（R5，联动环境输入、焦面和显示预算）。R3 在同一遮挡片段上扩展动态遮挡比例和跟踪，R6 将三个演示串为三分钟回放。传统策略在同一输入上显示固定告警，形成课堂对照。

视觉资产均由项目程序生成，包括路面纹理、车辆箱体、路牌、树木和山体。采用低饱和自然光、石墨座舱与少量有含义的状态色。R2 更换网格和材质时需保留米制尺寸、眼点、裁切及可重复轨迹。视觉验收优先检查货车后门与隐藏车辆线框的空间关系，以及失效后是否还残留看似精确的图形。

## R3 驾驶视图

画布铺满视口。A 柱、顶棚密封边、方向盘和仪表台构成视野边界，玻璃使用视角相关的轻微反射。默认控制台收起；操作浮条保留播放、HUD、教学揭示和抽屉入口。场景标题短暂入场后淡出。世界标记按定位质量采用车形与接地环、虚线估计区域或固定方向提示；接近风险使用琥珀色。教学状态暂停并标引遮挡车、实车和路侧估计，退出后恢复原来的镜头和时钟。

## R4 驾驶与叙事

驾驶主画布继续铺满视口。右上方场景选择器切换三种预设，底部浮条在路口提供研究投影，在货车场景提供教学揭示。默认 DRIVE 维持前向相机，侧向风险出现在来车一侧。研究画面以同一眼点压缩单侧外围，同时投影车辆和地面估计轮廓。对照模式上、下两带分别显示标准与左侧扩展的相同道路区域。叙事使用按章出现的文字与连续世界镜头，滚动及自动播放共享进度。
