# 技术决策记录

## ADR 001 保存原始材料并建立证据层 2026-11-19

根目录实际文件带 `(1)`，与总控标准路径不同。保留原件，复制到 `references/` 标准路径；用SHA-256验证一致。提取全部正文与媒体，不移动或改写原文。关键公式为图片，需手工阅读转录并注明歧义。

## ADR 002 首轮使用可控 3D 场景

需要目标运动、遮挡深度与投影一致，采用轻量自建Three.js场景和SVG HUD；不在首轮部署CARLA服务。R2可在统一数据契约下替换高质量资产。任何简化都要如实标明，不能把程序化首轮场景称为已达到Photorealistic。

## ADR 003 真值与估计分离

场景真值只供可视场景和模拟传感器输入；HUD经过时间、质量和显示策略。固定随机种子及事件历史，支持seek复现。如此延迟和丢包能改变真实判断，而非只改变标签。

## ADR 004 时间戳优先于时延分位数

材料图称p90外推，正文指出p90偏差。按消息实际age补偿，p90只用于统计与预算。R1恒速模型和有限外推上限是工程假设；不声称解决任意运动、不确定时钟偏差与真实通信抖动。

## ADR 005 质量与风险独立编码

存在可信度决定状态文字/线型，位置协方差决定包络与world-lock可用性，风险决定颜色与优先级。严重风险不因位置不足直接消失；但依据过期后不能无限保留目标指向，须转不可用状态。阈值为待验证仿真参数。

## ADR 006 准备工作不计为 R1 完成

本次总控要求保存持续约束并准备第一轮，因此只建立材料证据、规格、架构及验收基线。无应用、不虚报构建或视觉效果；R1进入实际实现后才执行程序构建及交互验收。

## ADR 007 R1 正式场景与边界

正式任务指定同向货车遮挡独立车辆，替代准备阶段的横穿行人。R1 采用单一 RSU 轨迹、固定眼点、横向 σ 与恒速预测。通过变道验证解除遮挡。后续接入横穿目标时扩展冲突区算法。程序化材质可替换，已在本机 Chrome 验证。

## ADR 008 R2 资产与渲染

选择可控 Three.js 城市街道、R3F 生命周期与本地许可资产。远景构件实例化，近景使用带材质车辆网格与真实内饰。观察视角隐藏只对驾驶员眼点有效的 HUD；切换相机保留时间和感知状态。纯时间函数继续驱动目标与自车。

## ADR 009 驾驶镜头与教学揭示

在 1440×900 比较水平 80°、88°、95° 后选 88°。按画布宽高比换算垂直 FOV。真实天空使用本地 HDR，材质沿用 PBR，默认 ACES Filmic。教学模式保留同一驾驶眼点、冻结感知帧，使用一个可逆进度控制焦角、货车材质和标引。正常驾驶始终恢复货车深度写入。比较图及选择理由见 [R3 验收](round3-verification.md)。

## ADR 010 单侧离轴 RenderTarget

驾驶研究视角覆盖前半空间。本轮选同眼点单次离轴宽视锥渲染，在屏幕 pass 中连续压缩外围。仅需一次街区几何绘制，正常与扩展的路口画面共用 HDR 颜色输出。多方向 RT 或 CubeCamera 可覆盖更大角域，也需要处理面间过滤及多次街区绘制；本轮未实现或测量六面方案。中心、导数、往返与真像素配准测试详见 [R4 记录](round4-verification.md)。

## ADR 011 局部显影与显示依据

空间显影采用真实目标车型的估计姿态、遮挡车像素 stencil 和车体深度预通过。示意车的车型一致是仿真假设。世界锁定的依据来自观测；只有教学模式同时展示真值。三档定位、跟踪稳定性、存在可信度和风险等级分别建模。

## ADR 012 · 按源模型长度统一注册

三轴分别适配同一车型的预设宽、高、长会改变造型。统一用目标车长除以源网格实长，保留原节点矩阵；外层只承载轨迹。目标、停车、故事自车和三维显影采用同一车型注册值。货厢沿用原设计，遮挡包络按组合体实测顶点范围更新。

## ADR 013 · 固定座舱通道与可恢复的镜头所有权

沿用单眼点离轴街景。座舱在自己的 RGBA 渲染目标中使用正常镜头，合成时读取固定座舱 UV。翼部垂直变换参照水平角放大率，水平线附近保留局部形状。Compare 裁切同一曝光的两个视图。Story 通过纯函数提交镜头轨迹，Inspect 单独申请相机所有权，离开后恢复驾驶眼点。

## ADR 014 · 单独注入天气、路侧定位与链路故障

相机能见度影响本车配准残差；RSU 覆盖边缘与位置质量控制测量误差；采样、到达与过期决定哪些包可用。三者可在同一时钟同步展示，也可在 Live Lab 分别固定。样例的噪声、阈值与丢包段均为教学设定。

## ADR 015 · 可逆影片与教学定格

七章按绝对影片秒编排。保留 Lab 的场景秒与实际采样时刻，允许固定一个场景帧比较不同输入。展开视野时固定路口场景秒 3.2，位置质量前三档对照固定雾区场景秒 4。随后恢复采样时钟，过期状态依据实际仿真消息年龄计算。渲染层描述已有决策，独立的风险等级继续由轨迹判断。光学部分本轮提取真实模型并交接章节进度，物理标定归入 R5B。

## R5B

- 在等角域对照下选择结构感知映射作为 Story 默认。已知梁缘使用直线约束，侧车使用同一眼点的局部切线透视校正形状。实验台保留原算法和 Pannini。
- 光路采用有限平面与单共轭曲面，反向找发射位置、正向逐面验证。VID 控件代表等效设计构型。三维镜面与光路图共用相同几何函数。
- 第 06 章从同一风险目标生成方向提示与中控空间图，镜头回到驾驶眼点收尾，七章长度合计 180 s。[验收数据](round5b-verification.md)
