# R6 Cinematic Final Cut

影片总长 180 秒。在分支 r6-cinematic-final-cut 制作，稳定 Preview 位于原根路径。独立入口为 /vista-driving-experience/r6/，实验室为同路径下的 ?lab。

| 时间（秒） | 观众所见 | 声音与衔接 |
| --- | --- | --- |
| 0–15 | 字形建立、定向解体、道路从消失点显露，镜头落入座舱 | 长音渐起，解体与入座声 |
| 15–45 | 货车遮挡、路侧位置显影、侧面验证 | 稳定脉冲与确认音 |
| 45–75 | 交叉路口从边缘预警进入侧向展开，随后收回 | 空间展开音与较密节奏 |
| 75–105 | 同一目标从精准、估计、方向、受限走到陈旧，再恢复 | 节奏减薄，状态提示 |
| 105–136 | 从座舱进入实体光机，主光束经过三个反射点，虚线指向虚像，回到座舱 | 高音延音与稀疏泛音 |
| 136–151 | 路面维持可见，有限显示域显现，眼点移出后虚像消失 | 降低节奏密度 |
| 151–167 | 风挡表达方向，中控短暂补全环境地图，随后回正 | 脉冲恢复 |
| 167–180 | 路口车辆横穿，品牌落版，末帧等待操作 | 和弦收束、提示音衰减 |

## 本机验收

Apple M4、16 GB、Chrome 157、ANGLE Metal。构建、TS 类型检查、23 项单元测试、12 项浏览器回归通过。包含资源尚未就绪时冻结时间、默认静音、音轨起点、跳章、暂停、Lab 切换、三维投影配准、五种感知状态、眼盒和恢复。生产包仍包含一个超过 Vite 默认大小提醒阈值的主 JS 块。

| Chrome 生产版采样 | 字形开场 | 路口章节开始 | 光学章节开始 |
| --- | ---: | ---: | ---: |
| 1440 × 900 | 59.7 | 59.7 | 59.8 |
| 1920 × 1080 | 46.9 | 52.4 | 54.1 |

单位为每秒更新的故事画面状态数。每组 6.5 秒，由 rAF 观测实际页面已提交的影片时间。结果受分辨率、GPU 和操作系统调度影响。1440 × 900 三分钟自动播放完整到达 180 秒，录制时观测到 9819 次时间更新。完整影片基于 Chrome 页面录制，截去操作片头，再按重播首帧合入项目内同一条配乐，混音增益与默认音量一致。短片从该影片截取。音频播放行为另用真浏览器验证，离线包成功解码 180 秒与 32 秒两条非静音音轨，切章后从 45 秒附近起播。

## 本地交付与复现

- 成片、15 秒开场、31 秒光学片段、14 个镜头截图、九格总览和性能源数据存于 docs/verification/r6。
- macOS Intel / Apple Silicon 离线包位于 release/vista-r6-final-cut.zip。实测从 ZIP 解压运行内置 HTTP 服务，Chrome 全部跨源请求受阻，四份 GLB、HUD、投影、状态降级、光学、双音轨与 Story/Lab 交互通过。验收 JSON 保存在 release/verification。
- npm run build 生成生产应用；npm run test:e2e 检查交互。启动本机生产服务后用 VISTA_URL 指定地址，运行 node scripts/r6-perf.mjs 或 node scripts/r6-capture.mjs。录制完整影片使用 --film。npm run package:offline 生成 macOS ZIP。
- 低性能入口 ?quality=low 使用稀疏字形及局部遮罩。光学表面、参考设计视场与车辆风险均为既有仿真，未进行实车测量。
