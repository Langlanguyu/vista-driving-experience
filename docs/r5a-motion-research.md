# R5A 影像与交互研究

本机 Chrome 初次刷新后内容区域呈空白。在独立的 Chrome 会话中等待预加载完成，随后以 420、1150、1800、3800 像素的滚轮输入向下浏览，再反向滚回。实际画面如下。[Rikoutaku / RI.Studio](https://www.rikoutaku.work/)

- 暗色预加载画面以细线圆、单点运动和角落的大号百分数标识进度。载入后切换为浅色留白、等距房间和下方短标题。
- 小幅下滚时，房间构件越过画面两侧，下方标题仍留在原位。继续滚动可看到跨宽度的大字被上边缘裁切，正文和小图形获得独立的留白。
- 作品区采用图像窗口，快滚捕捉到蓝色遮片只覆盖部分图像的中间帧。更深处出现深色背景与另一个角度的房间，反向滚回能重新得到入口构图。以上为浏览器采样观察；未验证原站内部着色器、精确缓动或源码结构。
- VISTA 采用固定画幅内的空间移动、字号反差、裁切和实物回归，用同一个驾驶员眼点展示技术差异。Codrops 首页本次返回 403。[Codrops](https://tympanus.net/codrops/)
