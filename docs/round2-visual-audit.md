# R1 驾驶画面审查

原应用在 Chrome 的 1440×900 桌面和 1920×1080 全屏各实拍一帧，见 verification/round2/before-desktop.png、before-full.png。桌面道路窗口约占屏幕面积 44%，上下有品牌栏、重复标题、场景标题、诊断条和三列控制台。视线在这些同等醒目的元素间移动。

现有引擎已使用透视三维场景，但货车的几何箱体、规则排列的树片、无建筑的道路和贴在镜头上的座舱边缘难以传达真实尺度。保留 ENU 坐标、统一时间、质量状态机、估计点投影、消息中断与恢复。R2 将车辆换成加载的模型，增加带进深的街面与建筑、实拍材质和天空光照，并把回放控件压缩到道路下方。
