# VISTA R6.2 交付验收

从 R6.1 的 bcd5b74 建立 r6.2-final-refinement。固定 Chrome 视口为 1920 × 1080，在同一条时间轴采集 27、60、97、180 秒。每组截图同时保存驾驶眼点、偏航与俯仰、场景秒数和投影强度。四组前后 JSON 逐字节相同。截图、视频与性能原始记录在本地 docs/verification/r62。

## 画质审查与选择

| 核查项 | R6 → R6.1 的实际改动与肉眼结果 | R6.2 决定 |
| --- | --- | --- |
| 原始天空 | noon.hdr 与独立反射图换为 Hausdorf。解码 1024 × 512 原件可见几乎无云的蓝天、偏浅的地平线与真实地景。太阳峰值在 (614,192)，红通道约 58854，相对线性辐射量。素材发布者标记 5400 K WB。 | 选有离散积云的 Kloofendal。上半球每条纬线估计晴空红蓝比，提取云覆盖率，另存 HDR 云亮度。65 KiB 的双通道 WebP 在线性数据空间采样。原 HDR 继续驱动反射，日间太阳仰角约 48°。 |
| 天际线 | 距离雾从 .0023 增至 .0028 m⁻¹，另有透明球将低于约 5.5° 的天空完全盖为灰蓝色，到约 14.8° 才消失。27 秒前视图中，货车上方的天空接近单色。 | 晴天用一个不透明天空球，沿仰角连续混合蓝色与近地散射；保留 .00165 m⁻¹ 距离雾。雾区密度仍随场景独立增加，雨丝与湿路面沿用原时间轴。 |
| 天光与阴影 | 日光移到 Hausdorf 太阳方向，背景强度 .88 → 1.04，晴天环境强度 .82 → .66。两车交汇时接地可见，车体材质细节在驾驶视角较小。 | 三组天空使用同镜头独立比较天空颜色、云阈值、主光、环境填充与远景雾。最终 B 的亮路面保留标线，蓝天颜色介于 A、C 之间。 |
| 地面与车漆 | 道路底色从 #9a9a96 变为 #858988，法线缩放 .38 → .57，干路粗糙度 .95 → .88。车漆金属度 .68、粗糙度 .29；物理材质另设清漆 .94 和清漆粗糙度 .095。增加目标车接地阴影。 | 保留这些实际生效的材质，在新日光下检查建筑侧面、交会车漆与路面；新晴天不对整幅城市图像统一增蓝。 |
| 输出与采样 | ACES、曝光 1.12 与默认 DPR 上限 1.25、离屏 MSAA 2× 延续 R6；新增低画质分支的 DPR 上限 1、离屏 MSAA 0。 | 同一 B 镜头复测 Neutral，更重的围墙暗部与路面阴影影响远景辨识。保留 ACES、线性渲染目标与最终 sRGB 输出。 |

同一片空域取屏幕区域 x=419…479、y=62…89 的 JPG 像素通道中位数。R6.1 为 (147,170,188)，A 为 (95,137,172)，B 为 (78,132,172)，C 为 (55,100,155)。97 秒的 V2X 过期镜头仍呈灰雾，车形已撤除。现有雨丝随雾区运行，当前版本未提供单独雨天或逆光预设。来源见 [Hausdorf](https://polyhaven.com/a/hausdorf_clear_sky) 和 [Kloofendal](https://polyhaven.com/a/kloofendal_48d_partly_cloudy_puresky)。

## 开场与控制

两段候选均为实时 Chrome 录屏。A 的 C 内缘直接裁出当前三维道路，车道线连续延伸到全屏；B 使用带厚度的 C 形距离场与偏转视线，可见实体侧面。B 的侧壁在穿越时占去较多画面，正式选择 A，生产着色器省去 B 的逐像素步进。两者使用相同的七章时钟，保持静止待机、单次下滑激活、自动过渡至驾驶员眼点。支持键盘、触摸与低画质模式。

## 本地证据与复测

- Skies.jpg 汇集三个晴天候选；Before-After.jpg 汇集四组同帧画面；Opening.jpg 为首次开场四个阶段。原分辨率文件分别位于 natural、automotive、cinema、neutral、before 及 after 目录。
- opening/aperture.mp4 和 opening/sculpture.mp4 为两种设计的动作预览；VISTA-R6.2.mp4 为连续 180 秒成片。音频由浏览器主增益之后的 MediaStream 捕获，剪辑时按开场标记对齐。
- npm run typecheck、npm test、npm run build 和 npm run test:e2e 覆盖类型、23 项单元测试和 14 项 Chrome 用例。包括实际 GLB 遮挡、左右 HUD 配准、五类证据、光路进出眼盒、滚动一次启动、声音拒绝与重试、暂停续播、跨模式静音。滚轮、触摸与键盘由 Chrome 输入事件复现，实体触控板手感仍需现场确认。
- npm run package:offline 生成 macOS 通用服务与静态资源。解压 release/vista-r62.zip 后双击 Start VISTA.command；测试在浏览器新上下文中封锁非本地来源。依据 release/verification/r62-offline.json 核对实际下载的四个 GLB、HDR、云数据、路面贴图及两首音乐。字样使用系统字体。

## 真机运行记录

Apple M4、16 GB，Chrome 157.0.8103.79，ANGLE Metal。每个镜头观察 6.5 秒，只在影片秒数变化时记录一次 rAF 时间。下表为每秒可观察的时间轴更新；没有测量 GPU 完成渲染或显示器扫描输出。

| 视口 | 开场 | 展开路口 | 光机 | 车外交会 | 全组最长间隔 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 1440 × 900 | 59.8 | 60.0 | 60.0 | 60.0 | 33.3 ms |
| 1920 × 1080 | 50.9 | 51.2 | 56.6 | 46.9 | 33.4 ms |

八段采样均未观测到超过 50 ms 的间隔。1080p 的车外交会负载最高。原始记录 perf.json 包含 P95、最慢间隔和长帧计数。开发工具不会测得投影教室设备的帧率、实车光学性能或真实道路安全收益。
