## R2 资产决策

优先沿用 B。先在目标演示机用 t=2.4、6、10 s 的同一镜头，比较货车轮廓、相机横纵投影、材质和车道尺度，并记录加载时间、帧间隔分布、显存占用（可获得时）及截屏。以下路线均需资产授权。

|路线|适合条件|需要实测或补齐|
|---|---|---|
|A CARLA 预渲染|能获得统一画面、深度及对象元数据，固定路线满足展示|离线生产成本、轴向转换、同步误差、序列大小及课堂机器解码能力。本轮未安装或运行|
|B 可控 2.5D / Three.js|自由换镜头、位置质量与轨迹可复现，本轮已有相机和遮挡模型|资产逼真度、纹理加载、投影误差与实际课堂 GPU 帧时间|
|C 视频加同步元数据|有授权固定镜头，并能获取每帧时间、内外参与目标轨迹|seek 精度、裁切宽高比、目标遮挡标签及图层同步。只有视频时不能闭合世界坐标链路|
