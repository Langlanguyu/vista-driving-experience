### 图片补充 五组公式原述

以下保留符号；图片原件可核对，禁止将转录直接当已验证实现。

1. F1 刚体变换图中写 `p^E = R_EW(p^W + t_W) + p^E_sensor = R_SE p^E + t_SE`。加号、串联等式与符号定义不充分，存在歧义。实现采用明确定义的齐次矩阵：`p_E = inverse(T_WE) p_W`、`p_W = T_WS p_S`，矩阵名表示“从右下标坐标系到左下标坐标系”。这属于工程推导，不是原公式逐字等价声明。采用局部 ENU 避免直接大数 WGS84 运算。
2. F2：`az=atan2(x_rel,z_rel)`；`el=atan2(y_rel,z_rel)`；`u_mm=c_x+f*tan(az−ψ_install)`。图片称针孔+眼点、常见VID 7–15 m；只能角度对齐，不把固定虚像深度当作真实目标深度。图未给完整纵向投影公式；实现需明示相机模型，垂直球面角与针孔归一化坐标不得混用。眼点偏离会产生视差。
3. F3：`occluded ⇔ z_occluder < z_target − ε ∧ cls∈{车辆,建筑,护栏}`。ε 是深度噪声余量；结合正文细化为刚性白名单并先检查同视线交叠。
4. F4：`p(t+τ)=p(t)+vτ+½aτ²`；CTRV 可沿圆弧。图写“τ必须用p90而不是均值，且包含渲染管线”；方差随τ增长，外推不能增加确定性。正文 P075 又指出按 p90 外推会系统滞后。保留冲突：实现按实际样本时间戳到目标渲染时刻的 age 外推，p90 仅用于链路统计/预算；恒速为 R1 明示假设，高阶模型不默认更可靠。
5. F5：`σ_total=√(σ_pose²+σ_time²+σ_calib²+σ_optics²+σ_eye²)`；`θ_err≈arctan(||v_rel||τ/d)`；`TTC=d_corridor/v_close`。RSS 假设独立且同单位；角误差转位置误差需距离，不能混加米和度。TTC 分母必须为正且路径存在冲突；横穿采用冲突点占用时间判断，不能套用纵向距离除速。近目标对配准更敏感。

## 进入实现的证据边界

- 已有依据：两份课程材料的原始论述与完整提取，可用于说明设计动机，不等于独立文献核验。
- 研究目标：改善风险感知、避险、稳定性、效率和信任；未来可按原材料建议指标评估，当前无实验结果。
- 概念方案：可变焦、风挡分区调光、主动曲面校正、驾驶员生理反馈；只做清楚标识的软件示意。
- 待验证数值：0.9/3.4 s、0.5°、100 ms/99.99%、周期和典型FOV/VID；引用公开参数前核验原始来源及适用条件。
- 仿真设置：R1 的每一个速度、阈值、噪声、眼点范围、失效时限需另存参数表并标注“仿真假设”，禁止借用材料目标冒充测量。
- 原材料透明度/对比度编码可保留为辅助，但遵循总控要求另设存在状态、位置包络和风险编码。
