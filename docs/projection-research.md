# 非对称宽视场中的结构保护

## 文献与取舍

Kopf、Lischinski、Deussen、Cohen-Or 和 Cohen 在全景域中指定感兴趣区域，构造连续的三维投影面。关注区域靠近局部平面，余下曲面承担展开。作者用多分辨率 MIPS 调整参数网格，再将预计算结果用于交互浏览。这适合人工标注的全景，动态街景还需要随相机重新确定约束。VISTA 直接从场景取得钢梁、道路方向和风险车辆，无需逐帧识别图像。[论文全文](https://graphics.uni-konstanz.de/publikationen/Kopf2009LocallyAdaptedProjections/Kopf2009LocallyAdaptedProjections.pdf)

Sharpless 等将球面方向先投到直立圆柱，再作中心投影。以水平角 θ、仰角 φ 表示，S=(d+1)/(d+cosθ)，横坐标为 S sinθ，纵坐标为 S tanφ。d=0 给出标准透视，d=1 给出圆柱立体投影。垂线与中心径向线保持直线，一般偏轴水平线仍会弯曲。每条射线可以独立计算。本实验的 PANNINI 用 d=1 的解析逆变换，仅在扩展翼使用，并匹配中央边界的一阶斜率与原算法的边缘角度。图像上、下边界的垂直收束是项目适配。[Eurographics 全文，第 4 节](https://diglib.eg.org/server/api/core/bitstreams/8e4c4755-e33a-4ea6-8dbd-44c5780d7307/content)

Carroll、Agrawala 和 Agarwala 对球面采样网格求空间变化的二维映射。局部保形约束控制角度变形，直线约束控制用户标记线段的共线性，区域权重调节二者的冲突。网格优化需要求解耦合的未知量。VISTA 采用有限的场景先验和有序列查表，适合反向拖动、任意 seek 与实时重建。[作者论文](https://doi.org/10.1145/1531326.1531349) · [论文及方法图解](https://graphics.stanford.edu/courses/cs478/lectures/02152012_panorama.pdf)

## 实现

世界、座舱和屏幕空间分开渲染。三种扩展算法共享同一个驾驶员眼点和真正放大的偏轴世界视锥。默认中心半宽为标准化坐标的 0.28。全强度扩展时，单侧新增约 20.18°。参数属于本项目仿真假设。NORMAL 使用相同眼点下的 88° 标准透视。

CURRENT 保留 R4.5 的二次翼部采样与竖直有界增益。PANNINI 用 q=2tan(θ/2) 参数化同一额外角域，翼内二次多项式匹配中央方向导数和外边界，纵向使用圆柱投影增益并平滑收边。STRUCTURE-AWARE 沿用 CURRENT 的横向映射。若三维梁缘在源视图投影为 y=mx+b，将该处纵坐标平移 m(u−x)，使显示梁缘落到中央直线的延伸上。路面区域根据道路消失点维持纵向路缘斜率。车辆区域取估计中心与车型八角点的投影范围，以同眼点、朝向目标中心的切平面作为局部形状基准，由车型包络在输出与切平面上的宽度比确定局部尺度，并约束其纵向坐标。这也消除了直接用视场外标准透视作为基准时已存在的边缘拉宽。此计算基准不会旋转实际驾驶摄像机。垂直边在所有算法中具有固定横坐标。没有对所有建筑立面独立设置硬约束。

在 129×65 的有序网格上，每列把输出纵坐标约束为严格递增并固定首尾，然后反解得到显示坐标到源射线的 RG 浮点纹理。GPU 双线性采样，CPU 反解同一列间插值，将目标锚定到像素。单次工作量 O(129×65)，着色器每像素多一次查表。中央及不扩展侧保留原始透视。所有权重由当前眼点、观测和时刻确定，切换方向通过已有连续强度控制器，逆向播放不会累积历史误差。外围压缩会损失采样分辨率，极端参数和其他街区的视觉接受度仍待测试。

## 度量

固定左侧路口 t=2.4 s，1440×900。梁缘以可见物理采样点到首尾弦的法向像素距离度量。车形比较横穿车型八角点的包络宽高比相对同眼点、朝向目标的局部切线透视之变化。同时报告相对原始宽透视的第二列数值，标准透视的包络可以落在屏幕外。中央位移取对称网格的最大误差。连续性取 60 Hz 下运动摄像机和缓动展开的 2 秒梁缘样本，同时记录最大相邻位移和最大二阶差分。图像证据另取自 Chrome，HUD 配准使用独立渲染的标记。R6 可把约束推广到多目标、立交桥侧面和更靠近视野边界的车辆。[数值结果](verification/round5b/geometry.json)
